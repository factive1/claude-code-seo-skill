# SEO + GEO content

Read `seo-geo-content-guide.md` in this directory in full before writing or editing anything. It is the source of truth. This file only says how to apply it.

## Before drafting

1. Ask for or find the author's voice samples. A sample overrides every pattern rule in the guide, including the dash rule.
2. Know the job: who the piece is for, where it will be published, and what the reader should do after reading it. Ask if the brief doesn't say.
3. Run the research in the guide's SEO and GEO sections. Collect every statistic, quote, and source you plan to use, with its URL, before you write a sentence.

## While drafting

Follow the four rules at the top of the guide. Never invent a fact. Match the voice samples. Every sentence adds something. Every sentence passes the portability test.

Put the keyword in the title, the H1, and one or two H2s. Open with what the reader doesn't already know from the query. Lead sections with a quotable statement. Use only sourced numbers, names, dates, and quotes, and leave `[SOURCE NEEDED: ...]` where you don't have one.

## After drafting

Run the guide's rewrite pass before the checklist: mark every tell strongest first, rewrite around the point, search for the five survivors (not-X-but-Y, one-line closer, dash, triad, bold label), check the ending, verify no fact was added, dropped, or smoothed into a generic claim, then read it aloud. Then run the final gate in the implementation checklist. If any item fails, fix it and run the checks again.

## Editing or auditing existing content

When the user asks whether a draft sounds like AI, name each pattern from the guide that appears, quote the line, and give the fix in a few words. Do not score the draft or guess whether AI wrote it. When the user asks for an edit, make the minimum effective edit: fix the tells, keep strong human sentences as they are, and list what changed. The writer should recognize the result as their own.

## What to return

The full draft, every `[SOURCE NEEDED]` marker listed at the end, and a short note on what voice samples or sources were used.
