# Claude Code SEO Skill

A comprehensive guide for writing content that ranks in traditional search and gets cited by AI systems—without sounding like it was written by one.

## What this is

This is a reference guide (and potential Claude Code skill) covering:

- **Traditional SEO**: Content structure, E-E-A-T signals, topical authority, technical requirements
- **GEO (Generative Engine Optimization)**: How to get cited by ChatGPT, Perplexity, Claude, and Google AI Overviews
- **Voice**: Detailed patterns for avoiding AI-sounding writing, with before/after examples
- **Implementation**: Checklists for before, during, and after writing

## Core principle

Rank in search. Get cited by AI. Sound like a human wrote it.

## Key sections

| Section | What it covers |
|---------|----------------|
| SEO | Content types, word count philosophy, style, research, structure |
| E-E-A-T | Experience, Expertise, Authoritativeness, Trustworthiness signals |
| Topical Authority | Hub-and-spoke content clusters |
| Technical SEO | Core Web Vitals, structured data, internal linking |
| GEO | AI citation mechanics, platform differences, research process |
| Voice | AI vocabulary to kill, grammar patterns, style fixes |
| Adding Soul | How to write clean prose that still has personality |

## Usage

### As a reference guide
Read it. Use the checklists. Run find/replace for the AI vocabulary lists.

### As a Claude Code skill
This can be converted into a SKILL.md that instructs Claude to follow these guidelines when writing content. The guide format works as documentation; the skill format would work as behavioral constraints.

## The tests

- **Would you say this out loud to a smart friend?** If not, rewrite it.
- **Is your key claim in a single, self-contained sentence an LLM could quote?** If not, restructure it.
- **Could you cut 20% without losing value?** If yes, cut it.
