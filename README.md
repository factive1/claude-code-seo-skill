# Claude Code SEO Skill

Write content that ranks in Google, gets quoted by ChatGPT and Perplexity, and doesn't make readers cringe.

## The problem

Most AI-written content has a tell. Actually, it has dozens of tells. Words like "delve" and "landscape." Sentences that end with "-ing" phrases tacked on to sound smart. Everything grouped in threes. Em dashes everywhere. "It's not just X, it's Y."

Readers spot it. Google's getting better at spotting it. And ironically, other AI systems are less likely to cite content that sounds like AI wrote it.

## What's in the guide

The main file (`seo-geo-content-guide.md`) covers two games you're playing simultaneously:

**Traditional SEO** — Getting Google to rank you. This means understanding E-E-A-T (experience, expertise, authority, trust), building topical clusters instead of isolated pages, and handling the technical stuff that lets Google actually crawl and render your content.

**GEO** — Getting AI systems to cite you. Perplexity, ChatGPT, Claude, and Google's AI Overviews all pull from different sources in different ways. The guide breaks down what sentence structures get quoted, what formats work, and how to research gaps in current AI answers.

The longest section is about voice. Specifically: 40+ patterns that make writing sound like AI, with before/after examples for each. Vocabulary to cut. Grammar tics to fix. Style patterns to avoid.

There's also a section on adding personality back in. Removing AI slop is half the job. The other half is not ending up with sterile, Wikipedia-style prose.

## How to use it

Read it once. Then use it as a reference.

The checklists at the end work as a pre-publish review. The vocabulary lists work as find/replace targets. The before/after examples work when you're stuck on why something sounds off.

You can also convert it into a Claude Code skill—instructions that constrain how Claude writes. The current format is a reference doc for humans. A skill version would be directives to Claude.

## Three questions to ask your draft

Would you say this to a smart colleague? If you'd feel embarrassed reading it aloud, rewrite it.

Can an LLM quote your main point in one sentence? If your key claim is buried or spread across paragraphs, restructure.

Could you cut 20% without losing anything? If yes, you should.
